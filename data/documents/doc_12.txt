Source: https://docs.vulkan.org/spec/latest/chapters/cmdbuffers.html

A command buffer is an object used to record commands which can be subsequently submitted to a device queue for execution. vkEndCommandBuffer ends the recording of a command buffer, and moves it from the recording state to the executable state. Command buffers in the executable state can be transitioned to the pending state by queue submission commands. A command buffer in the pending state must not be modified by the application, as it may be executing on the device. Once commands in the command buffer have completed all execution, the command buffer is immediately in either the executable state, or in the invalid state if it was recorded with the VK_COMMAND_BUFFER_USAGE_ONE_TIME_SUBMIT_BIT flag. A command buffer in the invalid state can be reset or freed.
